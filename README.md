# ☕ Maratona Java - DevDojo (Virado no Jiraya)

Este repositório foi criado para documentar e organizar toda a minha jornada de estudos na **Maratona Java** do canal DevDojo, ministrada pelo William Suane. O objetivo principal é consolidar a minha base acadêmica em Análise e Desenvolvimento de Sistemas (ADS) através de muita prática, commits constantes e evolução contínua no ecossistema Java.

🚀 **Status atual:** Mais de 105 aulas concluídas e aplicadas em código!

---

## 🛠️ Tecnologias e Conceitos Utilizados

- **Linguagem Principal:** Java (JDK 17+)
- **Paradigma:** Programação Orientada a Objetos (POO)
- **Ferramentas:** IntelliJ IDEA / Eclipse, Git e GitHub

---

## 📂 Estrutura de Aprendizado (Até a Aula 105)

O código deste repositório está dividido em pacotes que refletem a evolução dos conceitos estudados na maratona:

### 1. Fundamentos da Linguagem
- Tipos primitivos e convenções de nomenclatura.
- Operadores (aritméticos, lógicos, relacionais e de atribuição).
- Estruturas condicionais (`if`, `else if`, `else`, `switch`).
- Estruturas de repetição (`while`, `do-while`, `for`).
- Arrays (unidimensionais e multidimensionais/matrizes).

### 2. Programação Orientada a Objetos (POO)
- Criação de classes, atributos e métodos.
- Passagem de parâmetros (referência vs. valor).
- Sobrecarga de métodos e construtores.
- Blocos de inicialização (estáticos e não-estáticos).
- Modificadores de acesso (`private`, `public`, `protected`).
- **Pilares da POO:** Associação, Herança e Polimorfismo.

### 3. Recursos Avançados da Linguagem
- Modificador `final` (classes, métodos e constantes).
- Classes Abstratas e Interfaces (regras de contrato).
- Tratamento de Exceções (`try-catch-finally`, `throw`, `throws` e exceções customizadas).
